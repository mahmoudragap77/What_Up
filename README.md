# What Up 📰

**What Up** is a simple Android news application that lets users browse the latest general news headlines in one place.

The app connects to **NewsAPI** to retrieve news articles and displays them in a clean, scrollable list. Users can pull down to refresh and get the latest available headlines.

## ✨ Features

* 📰 Browse the latest news headlines
* 🔄 Pull-to-refresh for new articles
* 🖼️ Display article images
* 🌐 Open news articles using their original URLs
* 🚫 Automatically filters removed articles

## 🛠️ Built With

* **Kotlin**
* **Android**
* **Retrofit** – API networking
* **Gson** – JSON parsing
* **Gradle**

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/mahmoudragap77/What_Up.git
```

Open the project in **Android Studio**, sync Gradle, and run the application on an Android device or emulator.

## 📡 API

The application uses **NewsAPI** to retrieve general U.S. headlines.
